# C Programming Projects

A collection of four C programming projects created for learning and practicing core C programming concepts.

## Author

**Sanni Kumar**

## Projects

### Task 1: Basic Calculator Program
A simple calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division

**Concepts used:**
- `switch-case`
- Variables
- Arithmetic operators
- `scanf()`
- `printf()`

### Task 2: Matrix Operations
A program that performs:
- Matrix Addition
- Matrix Multiplication
- Matrix Transpose

**Concepts used:**
- 2D arrays
- Functions
- Nested loops
- Matrix operations

### Task 3: Student Management System
A menu-driven program for managing student records.

**Features:**
- Add student
- Delete student
- Update student
- Search student
- Display students

**Concepts used:**
- Structures
- Functions
- File handling
- `fread()` / `fwrite()`
- `fseek()`

### Task 4: Banking System
A mini bank account management system.

**Features:**
- Create account
- Deposit
- Withdraw
- Balance enquiry
- Exit

**Concepts used:**
- Structures
- Functions
- File handling
- Menu-driven programming

## Requirements

- C compiler such as GCC
- Any C-compatible IDE or code editor

## How to Run

Compile a program using GCC:

```bash
gcc filename.c -o program
```

Run it:

```bash
./program
```

On Windows:

```bash
program.exe
```

## Learning Objective

These projects are designed to practice important C programming concepts and gradually move from basic programming to small real-world applications.
